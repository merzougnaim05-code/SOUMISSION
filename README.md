# برنامج الاستشارات — المؤسسات التربوية

برنامج ويب لإدارة استشارتي **تموين المطعم المدرسي** و**التدفئة المركزية**: تسجيل الحصص/الأشغال والمتعهدین والعروض، التقييم والترتيب آلياً، ثم إصدار كل الوثائق القانونية جاهزة للطباعة أو التصدير إلى Word وExcel.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
```

## الوحدتان

| | 🍽 تموين المطعم | 🔥 التدفئة المركزية |
|---|---|---|
| البيانات | 4 حصص (خضر وفواكه، مواد غذائية، خبز، لحوم وبيض) | 8 بنود أشغال (مراجل، مضخات، صمامات...) |
| التقييم | العرض الأقل ثمناً لكل حصة | تنقيط تقني /40 (علامة دنيا 20) ثم الأقل ثمناً TTC |
| الوثائق | إعلان، كشف احتياجات، تصريح ترشح، دفتر شروط تقني ومالي، محاضر، مقارنة، نتائج، عقد تموين | إعلان، دفتر الشروط الكامل (86 مادة)، جدول أسعار، DQE، مذكرة تقنية تبريرية، أمر انطلاق الأشغال، مقارنة، نتائج |

كل النصوص القانونية في دفاتر الشروط **قابلة للتعديل** من داخل البرنامج (تبويب «دفاتر الشروط» / «دفتر الشروط») وتنعكس فوراً على الوثائق المطبوعة وتصدير Word.

## الميزات المشتركة

- 🖨 طباعة/حفظ PDF لكل وثيقة (A4، اتجاه RTL، خط Amiri)
- ⬇ تصدير Word (.doc) للوثيقة المعروضة
- ⬇ تصدير Excel متعدد الأوراق لكل بيانات الوحدة
- 💾 حفظ تلقائي في المتصفح (localStorage) لكل وحدة على حدة
- تفقيط المبالغ بالحروف العربية تلقائياً

## التقنيات

React 19 + TypeScript + Tailwind CSS 4 + Vite + SheetJS. النشر: `npm run build` ثم أي خادم ملفات ثابتة.
